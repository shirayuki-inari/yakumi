使用说明

  1. 选择视频

    上传视频，或点“服务器”选择服务器上已有的文件；也可以切换到“视频链接”粘贴网址（服务器需要安装 yt-dlp）。原语言默认自动识别；“翻译成”选择“不翻译”时只识别原文。已经有字幕时切换到“已有字幕”，导入 SRT / VTT 直接翻译，也可以附带视频用于预览和烧录。

  2. 等待处理

    依次进行语音识别、断句、翻译。可以关闭页面，任务会在后台继续。

  3. 校对字幕

    在任务页逐条修改原文和译文，点击视频下方的字幕行可以跳到对应位置。

  4. 导出

    选择单语或双语、字幕格式，以及是否把字幕烧录进视频，然后下载。

  5. 术语表

    把人名、专有名词的固定译法和节目背景保存成术语表，上传时选用，可以在多个视频里复用。

识别和翻译的服务地址、模型和密钥在 设置 中修改，那里也可以检查运行环境和测试连接。
